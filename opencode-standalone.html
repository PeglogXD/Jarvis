Privacy

Built for privacy first

OpenCode does not store any of your code or context data, so that it can operate in privacy sensitive environments. Your code stays on your machine — we only proxy to your chosen LLM provider. Self-hostable, auditable, open source.

FAQ
What is OpenCode?
OpenCode is an open source AI coding agent available as TUI, desktop app, and IDE extension. It helps you understand, plan, and build features with any LLM.
How do I use OpenCode?
Install with curl -fsSL https://opencode.ai/install | bash then run opencode in your project. Try /init to generate AGENTS.md.
Do I need extra AI subscriptions?
No — Zen includes free optimized models, or connect your existing Claude / GPT / Gemini keys. 75+ providers supported.
Can I only use OpenCode in the terminal?
No — use it in the terminal (TUI), desktop app, VS Code / JetBrains extensions, or web.
Is OpenCode open source?
Yes — MIT licensed on GitHub. 208K stars, 950 contributors, 13K+ commits.
